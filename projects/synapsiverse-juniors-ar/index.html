Synapsiverse Juniors AR

Built an iOS Unity AR app with a custom Objective-C++ native plugin running YOLO and DepthAnythingV2 entirely on-device — stable 30 FPS.

UnityC#Objective-C++iOSYOLODepthAnythingV2AR

Synapsiverse Juniors is an educational AR platform for children. I built the iOS Unity application, including a custom Objective-C++ native plugin that runs YOLO object detection and DepthAnythingV2 monocular depth estimation entirely on-device — no server, no cloud inference. The plugin bridges into Unity via callbacks, with 2D coordinate output mapped to Unity screen space for accurate AR placement.

Responsibilities

  • Custom Objective-C++ native plugin development
  • On-device YOLO object detection integration
  • DepthAnythingV2 monocular depth estimation integration
  • 2D-to-Unity screen space coordinate mapping
  • iOS process queue optimization for 30 FPS stability
  • Face tracking AR — GlowBrush experience
  • Marker-based AR — FridgeFriends experience
  • Unity AR implementation and scene management

Outcome

Shipped an iOS app running YOLO, DepthAnythingV2, and Unity AR simultaneously at a stable 30 FPS, all on-device. The process queue architecture on iOS was the critical optimization — without it, the models and the Unity render loop contended for CPU time and frame rate collapsed. The project is the deepest native work I've done: writing Objective-C++ plugins, bridging between native and managed runtimes, and tuning model inference to fit a real-time render loop.
